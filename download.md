## Download

### Pre-built Binaries

Download the latest release from
[GitHub Releases](https://github.com/TreeDoctor/TreeDoctor/releases):

| Platform | File | Type |
|----------|------|------|
| Windows (x64) | `TreeDoctor_0.1.0_x64.exe` | Standalone executable (no install) |
| Windows CLI | `treedoctor.exe` | Command-line tool |
| macOS | `.dmg` | Universal Binary (Intel + Apple Silicon) |
| Linux | `.AppImage` + `.deb` | Portable + Debian package |

> The Windows GUI executable is a **standalone file** — double-click to run, no
> installation required. It uses the system WebView, keeping the download size
> under 10 MB.

### Build from Source

**Prerequisites:**

- Rust 1.75+ (2021 edition)
- Node.js 18+
- For GUI: platform WebView (pre-installed on most systems)

```bash
# Clone the repository
git clone https://github.com/TreeDoctor/TreeDoctor.git
cd TreeDoctor

# Build the CLI
cargo build --release
# Output: target/release/treedoctor

# Build the GUI application
cd gui
npm install
npm run tauri build
# Output: target/release/bundle/
```

### Usage

#### CLI

```bash
# Analyze an IQ-TREE output directory
treedoctor analyze ./iqtree_output/

# Specify output format (text | json | markdown | html)
treedoctor analyze ./iqtree_output/ -f json -o report.json

# Check file completeness without full diagnosis
treedoctor check ./iqtree_output/

# List all available diagnostic rules
treedoctor rules
```

#### GUI

1. Launch `TreeDoctor.exe`
2. Click **"Browse..."** to select your IQ-TREE output directory, or
3. **Drag and drop** a directory or `.iqtree` file directly onto the window
4. Click **"Start Diagnosis"**
5. Explore the interactive dashboard — navigate dimensions, inspect trees,
   review cross-validation results
6. **Export** the report in your preferred format (Text / Markdown / HTML / PDF)

### Test Data

A sample IQ-TREE output dataset is included in the repository at
`test-data/example/`, generated by IQ-TREE 2.4.0 on 17 vertebrate mitochondrial
DNA sequences (1,998 sites):

```bash
# Run TreeDoctor on the test data
treedoctor analyze ./test-data/example/
```

This dataset exercises several diagnostic rules:
- 8 sequences fail the composition chi-square test (D1-R1, 47.1% failure rate)
- 2 low-support nodes with UFBoot of 71% and 46% (D5-R1)
- Single-threaded run on a 16-core system (D8-R1)
