# TreeDoctor 项目概述

## 1. 项目背景

IQ-TREE 是目前系统发育学领域使用最广泛的似然法建树软件之一，支持 IQ-TREE 2（v2.4.0）和 IQ-TREE 3（v3.1.4）两个主要版本。一次典型的 IQ-TREE 分析会产生多个输出文件，包含模型选择、似然值、分支支持值、序列质量统计等关键信息。然而，这些信息分散在 `.iqtree`、`.log`、`.treefile`、`.contree`、`.splits.nex`、`.mldist`、`.model.gz` 等多个文件中，研究者需要人工交叉核对才能判断分析质量，这一过程既繁琐又容易遗漏关键问题。

**TreeDoctor** 旨在自动化这一过程：解析 IQ-TREE 的全部输出文件，进行综合交叉验证，生成一份清晰、可操作的质量诊断报告，帮助研究者快速识别潜在问题，降低系统发育分析被误读的风险。

## 2. 项目目标

### 2.1 核心目标

| 编号 | 目标 | 描述 |
|------|------|------|
| G1 | 全文件解析 | 自动识别并解析 IQ-TREE 产生的所有输出文件类型 |
| G2 | 质量诊断 | 对分析的每个环节进行多维度质量评估，输出评级和建议 |
| G3 | 交叉验证 | 跨文件交叉核对数据一致性，发现潜在矛盾 |
| G4 | 双形态交付 | 同时提供 CLI（命令行）和 GUI（桌面应用）两种使用方式 |
| G5 | 版本兼容 | 兼容 IQ-TREE 2.x 和 IQ-TREE 3.x 的输出格式差异 |

### 2.2 非目标（明确不做的事）

- TreeDoctor **不重新运行** IQ-TREE 分析，不替代 IQ-TREE 本身
- TreeDoctor **不修改** IQ-TREE 的输出文件
- TreeDoctor **不进行**新的系统发育推断或模型计算
- TreeDoctor **不是**树可视化工具（但会调用外部工具或嵌入轻量可视化）

## 3. 适用用户

| 用户类型 | 典型场景 | 推荐界面 |
|----------|----------|----------|
| 生物信息学研究者 | 批量检查多次分析结果 | CLI |
| 进化生物学研究者 | 交互式查看单次分析质量 | GUI |
| 教学场景 | 向学生解释系统发育分析各指标含义 | GUI |
| 流水线集成 | 在自动化流程中嵌入质量检查步骤 | CLI（JSON 输出） |

## 4. 技术选型概览

### 4.1 GUI 框架：Tauri

| 维度 | Tauri | Electron |
|------|-------|----------|
| 安装包体积 | ~3-10 MB | ~50-150 MB |
| 内存占用 | 低（使用系统 WebView） | 高（捆绑 Chromium） |
| 后端语言 | Rust（高性能、内存安全） | Node.js |
| 安全性 | 更强（默认最小权限） | 需额外配置 |
| 跨平台 | Windows / macOS / Linux | Windows / macOS / Linux |

**决策**：选择 **Tauri 2.x**，理由：
1. 解析 IQ-TREE 输出文件涉及大量文本解析和数据交叉验证，Rust 后端提供高性能和可靠性
2. 安装包体积小，适合科研用户分发
3. Tauri 2.x 支持进程间通信（IPC）和插件系统，便于未来扩展

## 5. IQ-TREE 输出文件清单

TreeDoctor 需要处理以下 IQ-TREE 输出文件（以 `prefix` 为文件前缀）：

| 文件 | 格式 | 内容概要 | 解析优先级 |
|------|------|----------|------------|
| `prefix.iqtree` | 纯文本 | **主报告文件**：对齐统计、模型选择、似然值、树信息、一致性树、时间戳 | P0（必须） |
| `prefix.log` | 纯文本 | **运行日志**：完整运行过程记录，含组成检验表、模型选择过程、迭代日志 | P0（必须） |
| `prefix.treefile` | Newick | **ML 树**：最大似然树的 Newick 格式，含分支长度和支持值 | P0（必须） |
| `prefix.contree` | Newick | **一致性树**：bootstrap 一致性树（仅启用 bootstrap 时产生） | P1 |
| `prefix.splits.nex` | NEXUS | **分裂网络**：bootstrap 分裂支持值 | P1 |
| `prefix.mldist` | 纯文本 | **似然距离矩阵**：基于 ML 模型的成对距离矩阵 | P2 |
| `prefix.model.gz` | gzip 文本 | **模型详情**：ModelFinder 所有候选模型的完整参数 | P2 |
| `prefix.bionj` | Newick | **BIONJ 树**：初始邻接树（用于比较） | P3 |
| `prefix.ckp.gz` | gzip 文本 | **检查点文件**：分析状态检查点，含迭代信息 | P3 |
| `prefix.parttrees` | Newick | **分区树**（仅分区分析）：各分区的子树，仅在分区分析时产生 | P3 |
| `prefix.iqtree` 内含 | ASCII art | **树图**：文本格式的系统发育树可视化 | 内嵌于主报告 |

## 6. 成功标准

1. 能正确解析 IQ-TREE 2.4.0 和 3.1.4 版本产生的全部标准输出文件
2. 诊断报告覆盖至少 8 个质量维度（详见诊断规则文档）
3. CLI 支持文本和 JSON 两种输出格式
4. GUI 提供交互式的树可视化和质量仪表盘
5. 在包含 17 条序列、1998 位点的测试数据上，解析+诊断总耗时 < 1 秒
