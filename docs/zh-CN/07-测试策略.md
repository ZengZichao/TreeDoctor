本文档定义 TreeDoctor 的完整测试策略，包括测试层级、覆盖率目标、测试数据管理和 CI/CD 集成。

## 2. 测试层级详细设计

### 2.1 单元测试

**目标**：测试每个函数和模块的独立正确性。

#### 2.1.1 解析器单元测试

每个解析器需要针对以下维度编写测试：

| 测试维度 | 说明 | 示例 |
|----------|------|------|
| 正常输入 | 典型的有效输入 | 标准 `.iqtree` 文件内容 |
| 边界情况 | 极端但有效的输入 | 只有 3 个序列的最小输入 |
| 缺失节 | 可选节不存在 | 无 ModelFinder 节（手动指定模型） |
| 缺失字段 | 某些字段不存在 | 无标准误 `s.e.` |
| 格式变体 | 同一字段的不同格式 | 科学计数法 vs 普通浮点 |
| 空文件 | 完全空的输入 | 空字符串 |
| 截断输入 | 不完整的输入 | 文件后半部分缺失 |
| 无效输入 | 格式错误的输入 | 非 IQ-TREE 输出文件 |

#### 2.1.2 测试用例模板

```rust
#[cfg(test)]
mod tests {
    use super::*;

    // 正常解析测试
    #[test]
    fn test_parse_iqtree_report_normal() {
        let content = include_str!("../test_data/example.iqtree");
        let result = IqtreeReportParser::parse(content);
        assert!(result.is_ok());
        let report = result.unwrap();
        assert_eq!(report.version, "2.4.0");
        assert_eq!(report.alignment.n_sequences, 17);
        // ... 更多断言
    }

    // 缺失可选节测试
    #[test]
    fn test_parse_without_modelfinder() {
        let content = include_str!("../test_data/no_modelfinder.iqtree");
        let result = IqtreeReportParser::parse(content);
        assert!(result.is_ok());
        let report = result.unwrap();
        assert!(report.model_finder.is_none());
    }

    // 解析模型对比表
    #[test]
    fn test_parse_model_table() {
        let content = "TIM2+F+I+G4      -21152.612   42383.224 +    0.069 ...";
        let entry = parse_model_entry(content).unwrap();
        assert_eq!(entry.name, "TIM2+F+I+G4");
        assert!((entry.logl - -21152.612).abs() < 0.001);
        assert!(entry.aic_in_confidence_set);  // + 号
    }

    // 边界情况：最小输入
    #[test]
    fn test_parse_minimal_alignment() {
        let content = "Input data: 4 sequences with 100 nucleotide sites";
        let aln = parse_alignment_info(content).unwrap();
        assert_eq!(aln.n_sequences, 4);
        assert_eq!(aln.n_sites, 100);
    }

    // 错误输入
    #[test]
    fn test_parse_invalid_input() {
        let content = "This is not an IQ-TREE report file.";
        let result = IqtreeReportParser::parse(content);
        assert!(result.is_err());
    }
}
```

#### 2.1.3 诊断规则单元测试

每条诊断规则需要：
- 一个"通过"用例（触发 A 或 B 评级）
- 一个"不通过"用例（触发 D 或 F 评级）
- 一个边界用例（触发临界评级）

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_d1_r1_all_pass() {
        let data = test_data_with_all_sequences_passing();
        let result = CompositionChi2Rule.evaluate(&data);
        assert_eq!(result.grade, Grade::A);
    }

    #[test]
    fn test_d1_r1_half_fail() {
        let data = test_data_with_n_failed(8, 17);
        let result = CompositionChi2Rule.evaluate(&data);
        assert_eq!(result.grade, Grade::C);
    }

    #[test]
    fn test_d1_r1_most_fail() {
        let data = test_data_with_n_failed(15, 17);
        let result = CompositionChi2Rule.evaluate(&data);
        assert_eq!(result.grade, Grade::F);
    }

    #[test]
    fn test_d1_r1_boundary_10_percent() {
        let data = test_data_with_n_failed(2, 20);  // 刚好 10%
        let result = CompositionChi2Rule.evaluate(&data);
        assert_eq!(result.grade, Grade::B);
    }
}
```

### 2.2 集成测试

**目标**：测试跨模块协作和端到端流程。

#### 2.2.1 解析器集成测试

```rust
#[cfg(test)]
mod integration_tests {
    use super::*;

    #[test]
    fn test_full_analysis_pipeline() {
        // 1. 发现文件
        let files = discover_files("test_data/example/").unwrap();
        assert!(files.contains_key(&FileType::IqtreeReport));
        
        // 2. 并行解析所有文件
        let parsed = parse_all(&files).unwrap();
        
        // 3. 构建统一数据模型
        let data = build_analysis_data(parsed).unwrap();
        
        // 4. 执行诊断
        let report = run_diagnostics(&data);
        
        // 5. 验证报告完整性
        assert!(report.alignment.is_some());
        assert!(report.model_finder.is_some());
        assert!(report.likelihood.is_some());
        assert_eq!(report.dimensions.len(), 8);
        assert!(report.overall_grade <= Grade::B);  // 示例数据应为 A 或 B
    }

    #[test]
    fn test_cross_check_consistency() {
        let report = analyze_directory("test_data/example/").unwrap();
        for check in &report.cross_checks {
            assert!(check.passed, "Cross check {} failed: {}", check.check_id, check.message);
        }
    }
}
```

### 2.3 端到端测试 (E2E)

**目标**：测试完整的用户交互流程。

#### 2.3.1 CLI E2E 测试

```rust
#[test]
fn test_cli_text_output() {
    let output = std::process::Command::new("./treedoctor")
        .args(&["analyze", "test_data/example/"])
        .output()
        .unwrap();
    
    assert!(output.status.success());
    let stdout = String::from_utf8(output.stdout).unwrap();
    assert!(stdout.contains("总体评级"));
    assert!(stdout.contains("D1"));
    assert!(stdout.contains("D5"));
}

#[test]
fn test_cli_json_output() {
    let output = std::process::Command::new("./treedoctor")
        .args(&["analyze", "test_data/example/", "-f", "json"])
        .output()
        .unwrap();
    
    let json: serde_json::Value = serde_json::from_slice(&output.stdout).unwrap();
    assert!(json["overall_grade"].is_string());
    assert!(json["diagnostics"].is_array());
}

#[test]
fn test_cli_exit_code() {
    let output = std::process::Command::new("./treedoctor")
        .args(&["analyze", "test_data/good_analysis/"])
        .output()
        .unwrap();
    assert_eq!(output.status.code(), Some(0));  // Grade A/B → exit 0
    
    let output = std::process::Command::new("./treedoctor")
        .args(&["analyze", "test_data/poor_analysis/"])
        .output()
        .unwrap();
    assert_eq!(output.status.code(), Some(2));  // Grade D/F → exit 2
}
```

### 3.2 测试数据生成

使用 IQ-TREE 实际运行生成标准测试数据：

```bash
# 标准测试数据
iqtree2 -s example.phy -m MFP -bb 1000 -alrt 1000 --prefix test-data/example/example

# 无 bootstrap
iqtree2 -s example.phy -m MFP --prefix test-data/edge_cases/no_bootstrap/no_boot

# 蛋白质数据
iqtree2 -s protein.phy -m MFP -bb 1000 --prefix test-data/edge_cases/protein_alignment/protein

# 手动指定模型
iqtree2 -s example.phy -m HKY+G4 --prefix test-data/edge_cases/no_modelfinder/manual_model
```

## 5. CI/CD 配置

### 5.1 GitHub Actions 工作流

```yaml
name: CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main, develop]

jobs:
  test:
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest, macOS-latest]
    
    steps:
      - uses: actions/checkout@v4
      
      - name: Install Rust
        uses: dtolnay/rust-toolchain@stable
        with:
          components: clippy, rustfmt
      
      - name: Install Tauri dependencies (Linux)
        if: matrix.os == 'ubuntu-latest'
        run: |
          sudo apt-get update
          sudo apt-get install -y libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev
      
      - name: Install pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9
      
      - name: Install Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm
          cache-dependency-path: gui/pnpm-lock.yaml
      
      - name: Check formatting
        run: cargo fmt --all -- --check
      
      - name: Lint with clippy
        run: cargo clippy --all-targets -- -D warnings
      
      - name: Run unit tests
        run: cargo test --lib
      
      - name: Run integration tests
        run: cargo test --test '*'
      
      - name: Run coverage
        if: matrix.os == 'ubuntu-latest'
        run: |
          cargo install tarpaulin
          cargo tarpaulin --out Xml --output-dir coverage/
      
      - name: Upload coverage
        if: matrix.os == 'ubuntu-latest'
        uses: codecov/codecov-action@v3
        with:
          file: coverage/tarpaulin-report.xml

  build:
    needs: test
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        include:
          - os: windows-latest
            target: x86_64-pc-windows-msvc
          - os: macOS-latest
            target: aarch64-apple-darwin
          - os: macOS-latest
            target: x86_64-apple-darwin
          - os: ubuntu-latest
            target: x86_64-unknown-linux-gnu
    
    steps:
      - uses: actions/checkout@v4
      - name: Install Rust
        uses: dtolnay/rust-toolchain@stable
      - name: Install pnpm
        uses: pnpm/action-setup@v4
        with:
          version: 9
      - name: Install Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: pnpm
          cache-dependency-path: gui/pnpm-lock.yaml
      
      - name: Build CLI
        run: cargo build --release -p treedoctor-cli
      
      - name: Build GUI
        run: |
          cd gui
          pnpm install --frozen-lockfile
          pnpm tauri build
```
