# TreeDoctor GUI 设计规范

本文档定义 TreeDoctor 桌面应用（基于 Tauri 2.x）的完整 UI/UX 设计规范，包括页面结构、交互流程、组件设计和视觉规范。

---

## 1. 技术栈

| 层 | 技术 | 版本 | 说明 |
|----|------|------|------|
| 桌面框架 | Tauri | 2.x | 提供跨平台桌面应用壳 |
| 后端语言 | Rust | 1.75+ | 与核心库共享代码 |
| 前端框架 | React | 18.x | 组件化 UI |
| 前端语言 | TypeScript | 5.x | 类型安全 |
| CSS 框架 | TailwindCSS | 3.x | 原子化 CSS |
| 图标库 | lucide-react | 0.451+ | 轻量 SVG 图标库 |
| 树可视化 | 自研组件 | 内置 | Newick 树 SVG 渲染（响应式 + 拓扑模式） |
| 图表库 | Recharts | 2.x | 数据可视化 |
| 状态管理 | Zustand | 4.x | 轻量状态管理 |
| 路由 | 自定义路由 | 内置 | 基于 useState 的轻量路由（桌面应用适用） |
| 导出对话框 | @tauri-apps/plugin-dialog | 2.x | 原生保存对话框 |
| 文件系统 | @tauri-apps/plugin-fs | 2.x | 文件写入 |

---

## 2. 应用窗口

### 2.1 窗口规格

| 属性 | 值 |
|------|-----|
| 最小宽度 | 900px |
| 最小高度 | 600px |
| 默认宽度 | 1280px |
| 默认高度 | 800px |
| 标题 | "TreeDoctor - IQ-TREE 分析质量诊断" |
| 图标 | TreeDoctor 图标 |

### 2.2 主题

- 默认主题：浅色（Light）
- 可选主题：深色（Dark）
- 主色调：绿色品牌色（`--td-primary`）
- 字体：系统字体栈（Segoe UI / Microsoft YaHei / SF Pro / Helvetica Neue）
- 评级颜色体系：A(绿) B(黄绿) C(黄) D(橙) F(红) N(灰/未评估)
- WCAG AA 对比度标准：所有文字/背景组合 ≥4.5:1

### 3.2 页面路由

| 路由 | 页面名称 | 说明 |
|------|----------|------|
| `/` | 首页/文件选择 | 选择 IQ-TREE 输出目录或文件 |
| `/overview` | 概览仪表盘 | 总体评级和各维度摘要 |
| `/alignment` | 对齐质量 | D1 维度详细诊断 |
| `/model` | 模型选择 | D2 维度详细诊断 |
| `/likelihood` | 似然与信息准则 | D3 维度详细诊断 |
| `/topology` | 树拓扑与分支长度 | D4 维度详细诊断 + 树可视化 |
| `/support` | 分支支持值 | D5 维度详细诊断 |
| `/bootstrap` | Bootstrap 收敛性 | D6 维度详细诊断 |
| `/consensus` | 一致性树一致性 | D7 维度详细诊断 |
| `/runtime` | 运行参数 | D8 维度详细诊断 |
| `/raw-data` | 原始数据 | 原始解析数据查看 |
| `/cross-check` | 交叉验证 | 跨文件一致性检查 |
| `/settings` | 设置 | 应用设置 |

│  │                                                           │  │

│  │                                                           │  │
│  │   [开始诊断]                                              │  │

**交互**：
- 点击"浏览"按钮打开目录选择对话框
- 支持拖放目录或 `.iqtree` 文件到窗口
- 选择目录后自动检测文件前缀（下拉框可选）
- 点击"开始诊断"后跳转到概览页面
- 分析过程中显示进度条
- 最近分析列表可点击快速重新打开

## 7. 响应式设计

## 8. 无障碍设计

- 所有颜色搭配满足 WCAG AA 对比度标准（≥4.5:1）
- 评级不仅用颜色区分，同时有字母标签（A/B/C/D/F/N）
- 评级徽章添加 `role="img"` 和 `aria-label` 属性
- 交互元素添加 `aria-expanded`、`aria-haspopup`、`aria-label` 属性
- Toast 通知使用 `role="status"` 和 `aria-live="polite"`
- 树可视化添加 `role="figure"` 和 `aria-label`
- 表格支持键盘导航
- 图表提供文本替代
- 所有可点击元素支持键盘操作（Enter / Space）
- 全站添加 `td-focus-ring` 焦点环样式

## 9. 国际化

- 默认语言：中文
- 可选语言：英文
- 使用自研翻译表（`lib/i18n.ts`）进行国际化管理，`Translation` 接口确保类型安全
- 评级标签、维度名称、页面标题、错误提示等均本地化
- 语言切换时自动同步 `<html lang>` 和 `document.title`
- 日期格式根据当前语言使用 `zh-CN` 或 `en-US` 区域设置
