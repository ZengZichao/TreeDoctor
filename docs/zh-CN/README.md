# TreeDoctor 文档

> TreeDoctor 是一款 IQ-TREE 分析质量诊断工具，通过自动解析 IQ-TREE 的全部输出文件，进行多维度质量评估和交叉验证，帮助研究者快速识别分析中的潜在问题。

## 测试数据

项目中包含了一组真实的 IQ-TREE 输出文件（位于 `test-data/example/iqtree_output_example.*`），由 IQ-TREE 2.4.0 对 `example.phy`（17 条脊椎动物线粒体 DNA 序列，1998 位点）运行生成，使用命令：

```bash
iqtree2 -s example.phy -m MFP -bb 1000 -alrt 1000 --prefix iqtree_output_example
```

该测试数据涵盖了：
- 标准的 ModelFinder + 建树 + UFBoot 分析流程
- 8 条序列未通过组成卡方检验（可用于测试 D1-R1，失败占比 47.1%，触发 D 级评级）
- 2 个低支持值节点（可用于测试 D5-R1，UFBoot 分别为 71% 和 46%）
- 单线程运行（可用于测试 D8-R1，系统检测到 16 核但仅用 1 线程）
- 完整的输出文件集（9 种文件类型：`.iqtree`、`.log`、`.treefile`、`.contree`、`.splits.nex`、`.mldist`、`.model.gz`、`.bionj`、`.ckp.gz`）
